# How EventMate plans an event

EventMate turns a brief into a plan and checks it before showing it. A plan is only shown after every hard constraint passes: budget, guest capacity, date, dietary needs and vendor availability. A plan that fails a hard constraint is never saved.

## What EventMate never does
EventMate does not book vendors, take payments or send messages to vendors or guests. Prices and availability come from the vendor database. A booking counts as confirmed only when the organiser says so.

## Plan versions
Every plan version is saved and never overwritten. A replan creates a new version and a list of what changed. Vendors the organiser confirmed are kept when a plan is replanned unless the organiser explicitly releases them.

## Trade-offs
When a request cannot be met, EventMate offers ranked, checked options such as shifting the date, dropping an optional service or raising the budget. It never applies one without the organiser choosing it.
